# Contributing

Keep changes small and aligned with one TODO item.

1. Read `AGENTS.md`, `PLAN.md`, and `docs/security-model.md`.
2. Propose a tool contract before implementing it.
3. Keep scientific logic in the upstream domain library.
4. Add behavior tests and protocol tests.
5. Run the verification commands from `README.md`.
6. Update completion markers only after verification.

Examples must use placeholders, `example.com`, loopback addresses, or the
documentation-only address ranges. Never include a real deployment topology or
secret.
